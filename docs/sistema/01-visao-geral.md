# Visão geral

O **AVAGYM** é uma plataforma web (PWA) de treino com três perfis:

- **Aluno**: segue programas guiados ou fichas do personal, registra treinos, acompanha a evolução e participa da comunidade.
- **Personal (profissional)**: verificado pelo admin (CREF/CREFITO), atende alunos vinculados, monta fichas e modelos, responde ocorrências.
- **Administrador**: gestão de contas, verificação, vínculos, planos/assinaturas, biblioteca, moderação, empresa/LGPD, auditoria e configurações.

Produção: **https://ornygym.avadesk.com.br** (único domínio). Uma pessoa pode ter mais de um papel (ex.: personal que também treina).
