# Persona — Aluna do personal

**Juliana Alves**, 41 anos, professora em Niterói. Prepara uma corrida de 10 km com o personal Bruno.

| Item | Detalhe |
|---|---|
| Objetivo | Seguir a ficha do personal sem pensar; tirar dúvidas rápido |
| Personal | Bruno (verificado, ativo) — convida pelo código dela |
| Aparelho | iPhone antigo (390×844), letra grande |
| Nível técnico | Baixo: usa WhatsApp; confunde "código" com "senha" |
| Medos | Digitar o código errado, perder o vínculo, telas que não entende |

Variação coberta: **Lia**, conta criada pelo próprio personal (senha provisória, plano do personal) — tem mais áreas travadas.

## Jornadas
1. **Convite**: recebe o convite em Perfil › Meus dados; por engano digita o código de outro aluno (popup explica); depois digita o código certo e aceita.
2. **Meus profissionais**: card no Perfil e página do profissional.
3. **Ficha do personal**: antes da ficha vê "Você está vinculado a…"; depois a ficha vira o único treino ativo.
4. **Treino**: começa a ficha, envia "Tenho uma dúvida", treina até o fim e salva; acompanha a dúvida.
5. **Áreas bloqueadas**: Biblioteca, publicar no feed, API do personal, painel admin; para a conta do plano do personal: Programas, Músculos e desvincular.

## Expectativas
- Entender o que é "código de convite" x "meu código".
- Ver a ficha aparecer sozinha quando o personal publicar.
- Mensagens claras quando algo está travado, com caminho para "Ver minhas fichas".

Suíte automatizada: `app/frontend/e2e/personas/aluno-do-personal.spec.js`.
