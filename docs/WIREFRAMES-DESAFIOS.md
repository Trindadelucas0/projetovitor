# Wireframes — Desafios (mobile 375 px, funciona em 320 px)

Capturas reais: `/workspace/desafios/` (assistente) e `/workspace/ranking/` (ranking, feed, comprovantes, admin).

```
┌ Comunidade ───────────────────┐   ┌ Criar desafio · etapa 2 de 5 ┐
│ [Feed][Desafios][Grupos]…     │   │ ████████░░░░░░  ① ② ③ ④ ⑤    │
│ [Explorar][Participando]…     │   │ Tipo   [Meta individual ▾]    │
│ 🔍 buscar   [Oficial][Semana] │   │ Métrica[Sessões válidas ▾]    │
│ ┌ card desafio ────────────┐  │   │ Duração (7)(15)(30)(90)(…)    │
│ │ Oficial · Em andamento   │  │   │ Início [__/__]  Fim [__/__]   │
│ │ Outubro ativo            │  │   │ "O dia final conta (23:59)"   │
│ └──────────────────────────┘  │   │ [Voltar]          [Avançar]   │
└───────────────────────────────┘   └───────────────────────────────┘

┌ Página do desafio ────────────┐   ┌ Gestão (criador) ─────────────┐
│ capa                          │   │ Visão geral: 12 participantes │
│ [Oficial][Em andamento][Aberto]│  │ 2 pedidos · 1 convite · v2    │
│ Nome · tipo · datas           │   │ [Feed][Comprovantes][Ranking] │
│ [Participar]                  │   │ [Editar][Encerrar inscrições] │
│ Abas roláveis: Resumo | Ranking│  │ Pedidos: Ana [Aprovar][Recusar]│
│ | Feed | Comprovantes | Pessoas│  │ Convites: código · validade   │
│ | Gestão                       │  │ Histórico de estados          │
└───────────────────────────────┘   └───────────────────────────────┘
```
Resumo inclui as **regras e versões** (menos abas no celular).
