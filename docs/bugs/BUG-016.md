# BUG-016 - POST /api/adm/qualifications/verify devolvia 500 com id inválido

- **ID:** BUG-016
- **Data:** 2026-10-16
- **Perfil afetado:** admin

## Passos para reproduzir
`POST /api/adm/qualifications/verify` sem `id` (ou id não numérico) -> 500.

## Causa raiz
`NaN` ia direto para a consulta em coluna bigint.

## Correção (arquivos alterados)
`app/api/pro.js`: valida `id` (inteiro seguro > 0) e devolve 400 `INVALID_INPUT`.

## Teste de regressão adicionado
smoke.mjs ("admin verifica habilitação").

## Lição / armadilha
Validar entrada antes do SQL; 500 em entrada ruim é bug.
