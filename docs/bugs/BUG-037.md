# BUG-037 - Autor "Equipe AVAGYM" inventado quando o programa não tem autor

- **ID:** BUG-037
- **Data:** 2026-10-16
- **Severidade:** BAIXA
- **Perfil afetado:** aluno (detalhe do programa)

## Passos para reproduzir
1. Abrir o detalhe de um programa sem `author_name`.
2. A tela mostrava "Equipe AVAGYM" como autor.

## Causa raiz
`views/guided/Programs.jsx` usava `p.author_name || 'Equipe AVAGYM'`: o fallback atribuía autoria à empresa sem que isso estivesse registrado.

## Correção (arquivos alterados)
- `app/frontend/src/views/guided/Programs.jsx`: o fallback agora é "Autor não informado".

## Teste de regressão adicionado
Revisão manual + build; e2e do catálogo segue passando.

## Lição / armadilha
Nunca inventar autoria em fallback de tela; mostrar a ausência.
