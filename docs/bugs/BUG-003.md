# BUG-003 - AD-40/43: /admin/painel para aluno/personal

- **ID:** BUG-003
- **Data:** 2026-10-16
- **Perfil afetado:** aluno, personal

## Passos para reproduzir
1. Entrar como aluno (termos aceitos) ou personal.
2. Abrir `/#/admin/painel`.
3. Tela errada/onboarding em vez do Início.

## Causa raiz
Não havia rota de fallback para `/admin/*` fora do perfil admin; e o Início redirecionava ao onboarding.

## Correção (arquivos alterados)
- `app/frontend/src/App.jsx`: não admin em `/admin/painel` → `<Navigate to="/hoje" replace state={{ noOnboarding: true }} />`; rotas pro ganham `/admin/*` → `/pro`.
- `app/frontend/src/views/guided/Today.jsx`: não redireciona ao onboarding quando `history.state.usr.noOnboarding`.

## Teste de regressão adicionado
`e2e/qa-regressao.spec.js` (Playwright, front 4459 → API 8797): "aluno em /admin/painel vai para Início, sem onboarding".

## Lição / armadilha
Toda URL de outro perfil precisa de destino explícito; redirecionamentos encadeados (rota → Início → onboarding) devem ser testados juntos.
