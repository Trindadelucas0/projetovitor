# BUG-013 - Mídia gravada em pastas fixas fora do DATA_DIR

- **ID:** BUG-013
- **Data:** 2026-10-16
- **Severidade:** MÉDIA
- **Perfil afetado:** todos (posts, desafios, mídia de exercícios, documentos do personal); infra/backup; testes

## Passos para reproduzir
1. Subir uma API de teste com `DATA_DIR` próprio e enviar mídia (post, desafio, documento do personal).
2. Os arquivos aparecem em `app/api/uploads` e `app/api/private/pro-docs` (pasta do código), não no DATA_DIR.

## Causa raiz
`community.js`, `challenge-feed.js`, `exmedia.js` (`api/uploads`), `identity.js` (`api/private/pro-docs`) e `lgpd.js` (exclusão) montavam o caminho a partir da pasta do código. Resultado: fora do backup, some no redeploy e a API de teste escreve na pasta real (foi o que aconteceu às 14:54–15:05 com a API :8817 do QA).

## Correção (arquivos alterados)
- `app/api/storage/index.js`: `UPLOADS_DIR` (`DATA_DIR/uploads` ou `STORAGE_LOCAL_UPLOADS_DIR`), `PRO_DOCS_DIR` (`DATA_DIR/private-docs` ou `STORAGE_LOCAL_PRODOCS_DIR`), `uploadFile()`/`proDocFile()` leem do DATA_DIR com fallback da pasta antiga. O segredo das URLs assinadas não lê mais `DATA_DIR/secret` (foi para o banco): `STORAGE_SIGNING_SECRET` ou `JWT_SECRET`.
- `community.js`, `challenge-feed.js`, `exmedia.js`, `identity.js`, `lgpd.js`: usam a camada de storage (lgpd apaga nas duas pastas).
- `app/api/db/backup.ps1`: zipa também `DATA_DIR/uploads` e `DATA_DIR/private-docs`.
- Novo `app/api/scripts/migrar-midia-data-dir.mjs`: copia (nunca apaga) para o DATA_DIR só os arquivos **referenciados no banco** configurado; simulação por padrão, `--aplicar` para copiar, `--lista` grava o relatório.
- Migração feita no PC do Lucas (banco avagym): 19 arquivos copiados (18 de `exercise_media.url`, 1 de `professional_documents.storage_path`); 156 sem referência ignorados. Relatório: `docs/bugs/anexos/BUG-013-migracao-midia-avagym.tsv`. Nada foi apagado.

## Teste de regressão adicionado
`v5-seguranca.mjs` (rate limit ligado, DATA_DIR de teste): 11/11. Antes/depois da suíte: `app/api/uploads` 145 -> 145 arquivos, `app/api/private` 30 -> 30; os uploads do teste caíram em `data_test/uploads`.

## Lição / armadilha
Nenhum módulo monta caminho de arquivo a partir de `import.meta.url`; tudo passa por `storage/index.js`. Pastas antigas ficam só como leitura até a limpeza autorizada.
