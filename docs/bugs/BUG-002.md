# BUG-002 - AD-27: conta liberada continua na fila de pedidos

- **ID:** BUG-002
- **Data:** 2026-10-16
- **Perfil afetado:** admin

## Passos para reproduzir
1. Aluno bloqueado pede liberação.
2. Admin libera pelo botão/lote (`POST /api/adm/access/set`).
3. O pedido continua "pendente" na fila.

## Causa raiz
`setAccess` (`accounts-v42.js`) atualizava `users.access_unlocked_at`, mas não fechava `unlock_requests` pendentes; só o `decide` fechava.

## Correção (arquivos alterados)
- `app/api/accounts-v42.js` (`setAccess`): ao liberar, marca os pedidos pendentes do usuário como `aprovada` (decided_by, decided_at, decision_note).

## Teste de regressão adicionado
`node --test test/qa-regressao.mjs` (API 8797, `DB_NAME=avagym_test`): "BUG-002 (AD-27): liberar a conta encerra o pedido pendente".

## Lição / armadilha
Estados duplicados (flag no usuário + pedido) precisam ser atualizados na mesma transação, em todos os caminhos.
