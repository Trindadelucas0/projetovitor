# BUG-011 - Migration 028 falha em banco novo

- **ID:** BUG-011
- **Data:** 2026-10-16
- **Perfil afetado:** infra/testes

## Passos para reproduzir
1. `powershell -File db\test-db-reset.ps1` (banco vazio).
2. Erro FK `equipment_parent_id_fkey`.

## Causa raiz
028 insere filhos de `elastico`, mas em banco novo as migrations rodam antes do seed que cria `elastico`. O banco real não percebeu porque o seed já tinha rodado.

## Correção (arquivos alterados)
- `app/api/db/migrations/028_equipamentos.sql`: insere `elastico` antes (`on conflict do nothing`); não altera o banco real (já aplicada).

## Teste de regressão adicionado
`test-db-reset.ps1` recria `avagym_test` do zero com sucesso: 42 migrations e seed aplicados.

## Lição / armadilha
Migrations não podem depender do seed; recriar o banco de teste do zero revela isso.
