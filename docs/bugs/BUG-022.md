# BUG-022 - HTTP não redireciona para HTTPS

- **ID:** BUG-022
- **Data:** 2026-10-16
- **Severidade:** MÉDIA
- **Perfil afetado:** todos (produção)

## Passos para reproduzir
1. `curl -I http://<app>/`.
2. 200 em vez de 301.

## Causa raiz
O Cloudflare repassa HTTP ao túnel e "Always Use HTTPS" está desligado na zona; não temos token de API da zona (o token do cloudflared é só do túnel).

## Correção (arquivos alterados)
- `app/web/gateway.mjs`: com `X-Forwarded-Proto: http` (enviado pelo Cloudflare) responde 301 para `https://`.
- Recomendado também ligar no painel: Cloudflare > avadesk.com.br > SSL/TLS > Edge Certificates > Always Use HTTPS (passo para o Lucas em `docs/DEPLOY-VPS.md`).

## Teste de regressão adicionado
Smoke de produção: `curl -I http://...` = 301.

## Lição / armadilha
Não dependa só do painel; o gateway garante o redirecionamento.
