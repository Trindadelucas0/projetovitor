# BUG-005 - Acessibilidade dos switches de Configurações

- **ID:** BUG-005
- **Data:** 2026-10-16
- **Perfil afetado:** todos

## Passos para reproduzir
1. Abrir Configurações com leitor de tela.
2. Switches sem nome; alvo de toque < 44px; "Rever orientações" < 32px.

## Causa raiz
Componente `Switch` não aceitava rótulo; sem área de toque estendida.

## Correção (arquivos alterados)
- `components/ui.jsx`: `Switch` aceita `label` → `aria-label`.
- `views/Settings.jsx`: rótulo nos 5 switches.
- `index.css`: `.sw::after` estende a área para 44px.
- `views/admin/AdminApp.jsx`: botão de rever orientações com `minHeight: 32`.

## Teste de regressão adicionado
`e2e/qa-regressao.spec.js` (Playwright, front 4459 → API 8797): "switches de Configurações têm nome acessível e alvo ≥ 44px".

## Lição / armadilha
Componentes de controle sem texto visível precisam exigir `label`.
