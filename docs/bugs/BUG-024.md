# BUG-024 - /api/health público expunha contagens/detalhes

- **ID:** BUG-024
- **Data:** 2026-10-16
- **Severidade:** BAIXA
- **Perfil afetado:** público

## Passos para reproduzir
1. `GET /api/health`.
2. Resposta com mais que `{ok:true}`.

## Causa raiz
Rota de diagnóstico reaproveitada como health público.

## Correção (arquivos alterados)
- `app/api/server.js`: `GET /api/health` devolve só `{ "ok": true }`.

## Teste de regressão adicionado
`v5-aceite-cadastro.mjs` (`deepEqual {ok:true}`).

## Lição / armadilha
Health público não diz nada além de "vivo".
