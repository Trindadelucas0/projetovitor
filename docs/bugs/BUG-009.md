# BUG-009 - Avatares fora do DATA_DIR

- **ID:** BUG-009
- **Data:** 2026-10-16
- **Perfil afetado:** todos

## Passos para reproduzir
1. Enviar avatar.
2. O arquivo vai para `api/uploads/pub` (perdido em redeploy/sem backup).

## Causa raiz
`PUBLIC_DIR` fixo no código da API.

## Correção (arquivos alterados)
- `app/api/storage/index.js`: `PUBLIC_DIR` = `STORAGE_LOCAL_PUBLIC_DIR` ou `DATA_DIR/public-media`; `migrateLegacyPublic()` copia (sem apagar) os arquivos antigos (6 migrados); leitura com fallback para a pasta antiga.
- `app/api/db/backup.ps1`: inclui `public-media` (validado: zip gerado).

## Teste de regressão adicionado
`test/v5-seguranca.mjs` (upload/exclusão LGPD usa `PUBLIC_DIR`).

## Lição / armadilha
Dados de usuário sempre dentro de DATA_DIR, que é o que entra no backup.
