# BUG-026 - Sem forma de testar a entrega de e-mail para quem não tem conta

- **ID:** BUG-026
- **Data:** 2026-10-16
- **Severidade:** BAIXA (operação)
- **Perfil afetado:** admin

## Passos para reproduzir
1. Querer confirmar que o Resend entrega para um endereço qualquer.
2. O único caminho era "esqueci a senha", que só envia para conta existente.

## Causa raiz
Não havia envio de teste no painel do admin.

## Correção (arquivos alterados)
- Novo `app/api/adm-email-test.js` e registro em `app/api/server.js`: `POST /api/adm/email-test` `{ "to": "..." }`, só admin, até 10 por hora, conteúdo claro de teste do AVAGYM; passa pelo `email_outbox` e devolve `provider_id` (id do Resend). Com e-mail desligado responde 503.

## Teste de regressão adicionado
`app/api/test/v5-aceite-cadastro.mjs` (admin 200/503, e-mail inválido 400, aluno 403).

## Lição / armadilha
Teste operacional não deve depender de dados de usuário.
