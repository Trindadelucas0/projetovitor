# BUG-029 - academ.avadesk.com.br fora do ar (TLS unexpected eof)

- **ID:** BUG-029
- **Data:** 2026-10-16
- **Severidade:** MÉDIA
- **Perfil afetado:** quem usa o endereço antigo

## Passos para reproduzir
1. `curl https://academ.avadesk.com.br`.
2. Falha de TLS/DNS.

## Causa raiz
Às 16:03 (BRT) o hostname público do túnel foi trocado de academ para ornygym no painel do Cloudflare; o registro DNS de academ saiu junto. O túnel é gerenciado pelo painel (token), sem API de zona disponível para nós.

## Correção (arquivos alterados)
- `app/web/gateway.mjs`: `CANONICAL_HOST`/`ALIAS_HOSTS`; um domínio antigo recebe 301 (GET/HEAD) ou 308 (demais) para `https://ornygym.avadesk.com.br`. PM2 `avagym-web` com `CANONICAL_HOST=ornygym.avadesk.com.br` e `ALIAS_HOSTS=academ.avadesk.com.br`.
- Passo do Lucas no painel: Zero Trust > Networks > Tunnels > túnel da VPS > Public Hostname > Add: `academ.avadesk.com.br` -> `http://localhost:4460` (recria o DNS). Depois disso o redirecionamento já funciona.

## Atualização (16/10, 16:24) - decisão do Lucas
academ.avadesk.com.br foi ABANDONADO; o único domínio é https://ornygym.avadesk.com.br. O redirecionamento (CANONICAL_HOST/ALIAS_HOSTS) foi retirado do gateway e do PM2, e academ saiu do CSRF_ALLOWED_ORIGINS. Nada a fazer no painel do Cloudflare.

## Teste de regressão adicionado
Teste local do gateway com `Host: academ.avadesk.com.br` = 301 para ornygym.

## Lição / armadilha
Ao renomear hostname no túnel, adicione o novo em vez de trocar o antigo.
