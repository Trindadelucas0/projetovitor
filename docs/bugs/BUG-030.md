# BUG-030 - /api/admin/programs devolve 404

- **ID:** BUG-030
- **Data:** 2026-10-16
- **Severidade:** INFO (esperado)
- **Perfil afetado:** admin

## Passos para reproduzir
1. `GET /api/admin/programs`.
2. 404.

## Causa raiz
Não existe rota GET nesse caminho: o catálogo editorial usa `GET /api/admin/program-reviews` e `GET /api/admin/program-review`; em `/api/admin/programs/*` só há ações POST (`publish`, `archive`, `revoke`, `badges`). Os programas guiados antigos do admin foram substituídos por esse fluxo editorial.

## Correção (arquivos alterados)
- Nenhuma mudança de código; documentado em `docs/sistema` (rotas da API).

## Teste de regressão adicionado
Coberto pelo `v3-sem-visitante.mjs` (lista de rotas).

## Lição / armadilha
404 em rota inexistente é o comportamento correto; QA deve usar as rotas listadas.
