# BUG-025 - HEAD /api/health não respondia 200

- **ID:** BUG-025
- **Data:** 2026-10-16
- **Severidade:** BAIXA
- **Perfil afetado:** monitoração

## Passos para reproduzir
1. `curl -I https://<app>/api/health`.
2. 404/405.

## Causa raiz
O roteador só tinha a chave `GET /api/health`.

## Correção (arquivos alterados)
- `app/api/server.js`: rota `HEAD /api/health` (200, sem corpo) e em `PUBLIC_ROUTES`; `v3-sem-visitante.mjs` atualizado.

## Teste de regressão adicionado
`v5-aceite-cadastro.mjs` (HEAD = 200).

## Lição / armadilha
Monitores usam HEAD; declare a rota.
