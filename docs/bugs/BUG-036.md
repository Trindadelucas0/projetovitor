# BUG-036 - /api/plan responde 400; paywall enforced:false; preços a definir

- **ID:** BUG-036
- **Data:** 2026-10-16
- **Severidade:** INFO
- **Perfil afetado:** QA

## Passos para reproduzir
1. GET /api/plan sem parâmetro: 400.
2. GET /api/billing/access: enforced false.
3. Planos com preço TBD.

## Causa raiz
`GET /api/plan?id=<uuid>` é o detalhe de uma ficha do personal (pro_plans); sem id válido, 400 é o correto. O paywall (`monetizacao_ativa`) fica desligado de propósito enquanto Individual e PRO não têm preço: ligar sem preço bloquearia o catálogo sem oferecer como contratar.

## Correção (arquivos alterados)
- Cobrança implementada (capítulo 18): página de planos, checkout, gestão, admin; catálogo reduzido a Grátis, Individual e PRO (049).
- Para ligar: definir preço e marcar À venda no admin, depois Monetização ativa. Nenhuma mudança de código pendente.

## Teste de regressão adicionado
`app/api/test/v5-cobranca.mjs` (com monetização ligada, PRO Grátis recebe FEATURE_NOT_INCLUDED em fichas públicas).

## Lição / armadilha
Separar "não implementado" de "desligado aguardando preço".
