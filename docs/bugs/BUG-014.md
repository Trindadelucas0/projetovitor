# BUG-014 - Banco novo fica sem organização padrão (is_default)

- **ID:** BUG-014
- **Data:** 2026-10-16
- **Perfil afetado:** infra/testes (avagym_test)

## Passos para reproduzir
1. `db\test-db-reset.ps1`. 2. `setup-e2e.mjs` falha lendo o tenant padrão; v3-fase2 falha em "membership na organização padrão".

## Causa raiz
A 018 marca `is_default` em tenants existentes, mas em banco novo roda antes do seed que cria o tenant `avadesk`.

## Correção (arquivos alterados)
- `app/api/db/migrate.js`: após criar o tenant no seed, marca `avadesk` como padrão se nenhum estiver marcado. Banco real não muda (já tinha).
- `app/api/db/test-db-reset.ps1`: para no primeiro erro (antes imprimia "ok" mesmo com falha).

## Teste de regressão adicionado
Recriação do avagym_test + v3-fase2 (33/33).

## Lição / armadilha
Igual ao BUG-011: migration não pode depender de dado do seed.
