# BUG-039 - Botão Sair (POST /api/logout) respondia ok mas não revogava a sessão

- **ID:** BUG-039
- **Data:** 2026-10-16
- **Severidade:** ALTA
- **Perfil afetado:** todos (menu → Sair)

## Passos para reproduzir
1. Fazer login e guardar o token/cookie.
2. Clicar em Sair (o front chama `POST /api/logout`): resposta 200.
3. Chamar `GET /api/auth/me` com o mesmo token: continuava 200 (sessão viva até expirar).

## Causa raiz
A rota legada `POST /api/logout` em `app/api/server.js` só limpava os cookies; não gravava o `jti` em `revoked_tokens` como faz `POST /api/auth/logout`.

## Correção (arquivos alterados)
- `app/api/server.js`: `/api/logout` chama `revokeRequestToken(req)` (cookie ou Bearer) antes de limpar os cookies.

## Teste de regressão adicionado
`app/api/test/v5-logout.mjs`: "BUG-039: POST /api/logout (botao Sair) tambem revoga, por cookie e por Bearer" (3/3).

## Lição / armadilha
Rotas legadas duplicadas precisam compartilhar a mesma função de logout.
